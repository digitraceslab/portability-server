donations.researcher_auth.tokens module

Lookups for static researcher tokens.

The researcher token itself is only ever used to obtain a session (see sessions.py); it is never accepted as API credentials directly.

donations.researcher_auth.tokens.resolve_researcher_token(raw_key)[source]

Return the live ResearcherToken for a raw key, or None.

Looks the key up by its stored hash and rejects it once its expires_at has passed.
