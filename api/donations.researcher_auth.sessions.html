donations.researcher_auth.sessions module

Session issuing, resolving, and cleanup for researcher API access.

A session is a short-lived credential exchanged for a researcher’s static token (see tokens.py). All /api/ endpoints other than the exchange itself authenticate with a session key, not the researcher token.

donations.researcher_auth.sessions.create_session(token)[source]

Issue a new session for a researcher token.

Returns (raw_key, session). The raw key is only available here; the session stores its hash. The session’s expires_at is RESEARCHER_SESSION_LIFETIME_SECONDS from now, capped at the researcher token’s own expires_at.

donations.researcher_auth.sessions.resolve_session(raw_key)[source]

Return the live ResearcherSession for a raw key, or None.

Looks the key up by its stored hash and rejects it once its expires_at has passed.

donations.researcher_auth.sessions.revoke_session(session)[source]

Delete a session, ending it immediately.

donations.researcher_auth.sessions.purge_expired_sessions()[source]

Delete all sessions past their expiry. Returns the number removed.
