donations.models.parquet_storage module

Storage behaviour shared by every donation type backed by files.

Sources differ in how archives arrive and how their contents are read, but not in how the result is stored or served: one encrypted Parquet file per data type per archive, combined into one file per type when the export is complete, and read back a page at a time.
