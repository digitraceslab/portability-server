donations.utils.keystore.openbao module

OpenBao transit engine backend: wraps keys without ever holding them.

The application authenticates with an AppRole, then calls the transit engine’s encrypt/decrypt endpoints for the configured key. Only small values (data keys, OAuth token strings) are sent; donated data itself never is.
